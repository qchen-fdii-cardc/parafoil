# 伞、降落伞与翼伞

## 伞的故事

断桥借伞非常浪漫，神舟十三号返回舱伞降着陆也非常浪漫。在这两种情况下，伞同样也非常致命。

![断桥借伞](https://ts1.cn.mm.bing.net/th/id/R-C.f82e066d7cc9d22a1f835724cb579e03?rik=nuPdsPtQ5AgpDQ&riu=http%3a%2f%2f5b0988e595225.cdn.sohucs.com%2fimages%2f20181220%2f01b67b963dbb40c7afa99e0917a728d3.jpeg&ehk=HgWTOm82G%2fsas0nVGnJ%2bW3eADvJdK9tdt5GahWJ7IYc%3d&risl=&pid=ImgRaw&r=0 "《白蛇传·情》海报 " )

最早利用伞形物体减缓降落速度的历史可以追溯到古代。传说中，莱昂纳多·达·芬奇在15世纪设计了一种降落伞的原型，尽管没有证据表明他曾经建造或测试过它。

![达芬奇手稿](https://ts1.cn.mm.bing.net/th/id/R-C.89a8f8d870d0576c034d03c9c9915fab?rik=YQ%2bw3rsHbvUHAA&pid=ImgRaw&r=0 "达芬奇手稿：降落伞的概念设计")

到了18世纪，法国的路易·塞巴斯蒂安·勒诺尔曼被认为是第一个成功使用降落伞的人，他在1783年从一座塔上跳下，使用了一种类似伞的装置来减缓他的下降速度。

![勒诺尔曼](https://ts1.cn.mm.bing.net/th/id/R-C.dbaa92006c49fd542123b26d4ac5bf1b?rik=e3TJzB2ICOwBdQ&pid=ImgRaw&r=0 "路易·塞巴斯蒂安·勒诺尔曼：第一个成功使用降落伞的人")

这东西看起来还真是挺像一个伞的，伞骨构成的承重结构、伞面构成的空气动力学外形，绳索悬挂降落物。现代的降落伞与这个完全类似，特别是环帆伞，除了去掉刚性支撑杆代之以径向加强带，各环形伞衣之间减小开伞冲击的平衡缝。

![环帆伞](https://p.turbosquid.com/ts-thumb/Gk/RKMcwI/WwBjlwYK/ringsailparachutepreview007/jpg/1457816827/1920x1080/fit_q87/110c74f7bc873b13aea2feb2d094907e959421ad/ringsailparachutepreview007.jpg "环帆伞：典型的现代降落伞")

十字伞，伞衣径向分为四片，构成十字形，因此得名。

![十字伞](https://tse1-mm.cn.bing.net/th/id/OIP-C.Y6JkANVrRGjn57PasFM1JwAAAA?rs=1&pid=ImgDetMain "十字伞：另一种典型的现代降落伞")

这种图片上起来非常浪漫的伞降过程，实际上由于气流的复杂性、柔性伞衣的大变形，开伞过程冲击载荷非常大，伞衣破坏、缠绕、撕裂、绳索断裂等现象非常常见。此外，伞降过程严重不可控，降落伞的飞行轨迹与降落点之间没有直接关系，降落伞的飞行轨迹与风速、风向、风切变、地面起伏等密切相关。

所以，研究降落伞的飞行过程，需要研究降落伞的空气动力学、降落伞的结构力学、降落伞的飞行动力学，是一个复杂而困难的问题。
